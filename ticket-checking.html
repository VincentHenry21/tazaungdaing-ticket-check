How the admin check works

1. Buyer shows the QR PNG or the ticket ID at the counter.
2. Admin scans or types it here and checks the name and phone match.
3. Admin taps Redeem. The ticket is marked redeemed with the time, and it appears in this report.
4. If the same ticket is checked again, it shows Already redeemed, so it cannot be used twice.
